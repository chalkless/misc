# InDesignの使い方
- 最初のドキュメント設定
  - 新規
  - ドキュメントのサイズを選ぶ。印刷 → A5 など
  - 文章メインだったらテキストフレームの自動生成にチェックを入れるといいような気もするけどどうかな
  - 右下に「マージン・段組」のボタンがあるのでクリック。3段組とかにする
  - 3段組のができる
- 割り付け
  - 画面左のツールボックスから縦組グリッドツールを選択。
  - テキストを置きたいテキストフレームの対角線をドラッグする
  - 原稿用紙みたいなテキストボックスが作成される
  - 右クリックして「フレームグリッド設定」
  - 行数や文字数を直す。3段組で16文字×20行とか。直すとボックスのサイズが変わるので行間（行送り）の数字も変更。行間9Hでピッタリくらい
 
- 段落設定
  - 原稿用紙みたいなところをダブルクリックすると文字が入力できるようになる。
  - すぐそばにフォントや文字サイズが出てくる。その中で段落スタイルと文字スタイルのボタンがあるのでクリックして段落スタイルを出す。
  - （このあたりは準備編）出てきたポップアップの右下の+をクリックして新しい段落設定を作ってしまう。そこの鉛筆マークで設定変更できる。
  - インデントとスペース でインデントの設定ができる。mmの単位になっているが、13Qなどと打てば自動でmmに直してくれる。

- 文字の流し込み
縦書きか横書きかを先に指定しておく。テキストはファイルに落としておく。ファイル > 配置 で。

- インデント
段落の中で設定可能

- 文字が90度傾く
  - 1文字の時は、右クリックで縦中横
  - 複数文字の時は段落の≡から縦書き中の欧文回転
